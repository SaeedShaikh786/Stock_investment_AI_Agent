# AI Investment Strategist

## Overview
The **AI Investment Strategist** is a Streamlit-based application that provides personalized investment insights and reports. It leverages advanced AI models to analyze stock performance, company fundamentals, and market trends to generate actionable recommendations for investors.

## Features
- **Market Analysis**: Compare stock performance over a 6-month period and rank stocks based on their relative performance.
- **Company Insights**: Fetch company profiles, financials, and the latest news.
- **Investment Recommendations**: Provide top stock recommendations based on market analysis and company fundamentals.
- **Final Investment Report**: Aggregate all insights into a structured, investor-friendly report.

## Technologies Used
- **Streamlit**: For building the interactive web application.
- **Yahoo Finance (yfinance)**: For fetching stock data and historical performance.
- **Pillow**: For handling and displaying images.
- **Plotly**: For creating interactive visualizations.
- **Google GenAI (Gemini)**: For AI-powered analysis and recommendations.
- **Python-dotenv**: For managing environment variables securely.
